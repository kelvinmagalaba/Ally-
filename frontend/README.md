# Welcome to your Lovable project



## Local Development

### Prerequisites
- Node.js (v18 or higher recommended)
- npm (or yarn/pnpm)

### Installation
1. Navigate to the project directory
```bash
cd -updated
```
2. Install dependencies
```bash
npm install
```

### Running the Server
Start the development server:
```bash
npm run dev
```
The application will be available at `http://localhost:5173` (or as specified in your Vite config).

### Building for Production
To create a production build:
```bash
npm run build
```
